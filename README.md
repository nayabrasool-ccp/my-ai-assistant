# 🤖 Personal AI Assistant Web Application

Welcome to my personal AI Assistant! This project is a functional chatbot designed to assist with coding queries, college subjects, and general technology concepts.

## 🚀 Features
* **Interactive Web Interface:** Built using **Streamlit** for a smooth mobile and desktop experience.
* **Smart AI Brain:** Powered by the cutting-edge **Google Gemini 2.5 Flash** model via official API integrations.
* **DevOps Best Practices:** Configured using secure environment secrets management to protect API keys.

## 🛠️ Technology Stack
* **Language:** Python
* **Frontend/Backend Framework:** Streamlit
* **AI Engine:** Google Generative AI (`google-generativeai`)
* **Version Control:** Git & GitHub
